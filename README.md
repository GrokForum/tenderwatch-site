# TenderWatch SA site

Public site for TenderWatch SA: a neutral, sourced register of South African government tender awards. **DRAFT.**

Every page carries a DRAFT label, a `noindex, nofollow` robots meta and a link to the privacy and contact page.
`robots.txt` disallows all crawling. The site uses no scripts, cookies, analytics or forms.

All files except `CNAME` and this README are generated by the register build (changes CHG-TW-006 and CHG-TW-008) and are
replaced as a whole on each build: `index.html`, `method/index.html`, `privacy/index.html`, `404.html`,
`robots.txt`, `register.csv` and `manifest.json`. Do not edit them by hand.

Privacy and contact: privacy@grokforum.site. Responsible party: GrokForum.
